# SUVA Tuberías y Conexiones — prototipo comercial

Sitio estático en HTML, CSS y JavaScript para consultar líneas de producto, armar un pedido y preparar una solicitud de cotización por WhatsApp.

## Archivos principales
- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive e identidad visual.
- `app.js`: catálogo, filtros, carrito, sucursales, formulario y generación de mensajes.
- `assets/`: logo, favicon e ilustraciones del catálogo.
- `CHANGELOG.md`: cambios, decisiones y datos pendientes de verificar.

## Uso
Abre `index.html` en un navegador moderno. Para una prueba más cercana a producción, sirve la carpeta con un servidor local, por ejemplo con VS Code Live Server.

No hay backend ni cobro en línea. Los botones de contacto abren WhatsApp, teléfono, Google Maps o la aplicación de correo del usuario.
